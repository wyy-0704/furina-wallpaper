## 同人构图与叙事

| 原作 | 可借鉴的设计 |
|---|---|
| [海老地理的水下芙宁娜](https://www.pixiv.net/artworks/112728301) | 屈膝侧坐，上身前倾，脸转回来。水面、斜光和少量气泡就能交代环境。 |
| [麦田的芙宁娜](https://www.pixiv.net/artworks/112010750) | 前景用抬膝形成轮廓，上半部留给脸和手势。浅色背景托出深蓝服装。 |
| [コユコム的雨中芙宁娜](https://www.pixiv.net/artworks/113332377) | 侧脸近景用一只眼、清楚的侧脸轮廓和雨光就能成立。 |
| [望月もち的芙宁娜](https://www.pixiv.net/artworks/112939796) | 低对比度的深蓝背景加前后交错的水线。水线从手边引出，给静态背景带来方向和层次。 |
| [Csyday《ボクの正義｜ボクの罪》](https://www.pixiv.net/artworks/113658539) | 本体和水中身影有不同的动作与神态。斜水光分隔两侧，较低的反差让观者晚一点才发现第二张脸。 |

## 壁纸排版

| 样本 | 观察要点 |
|---|---|
| [竖屏壁纸 · PixieWall](https://www.pixiewall.com/wallpaper/furina-genshin-impact-24333) | 比较人物在竖屏中所占的面积，以及不同裁切下礼帽、脸和手的位置。 |
| [竖屏壁纸 · UHDpaper](https://www.uhdpaper.com/2023/07/furina-genshin-impact-4k-71m.html?m=1) | 用手机尺寸预览，判断锁屏时钟是否会盖住脸或头饰。 |
| [横屏壁纸 · Alpha Coders](https://wall.alphacoders.com/big.php?i=1328868) | 观察人物和远景在横屏中的分布，以及图标可以放在哪一侧。 |
