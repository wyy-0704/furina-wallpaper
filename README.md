# 芙宁娜角色壁纸工作流

一份给 ChatGPT 或 Codex 读取的二创指南，用于制作以芙宁娜为主角的手机或电脑壁纸。首版以荒性原服为主，包含实机和官图参考、同人构图拆解，以及生成后的审图步骤。

[查看完整工作流和参考索引](furina-wallpaper-workflow.md)

## 在新对话里使用

把下面这段复制到新对话，把「神性」换成你想画的主题。

> 先读 https://github.com/wyy-0704/furina-wallpaper/blob/main/furina-wallpaper-workflow.md ，按里面的方法给我生成一张芙宁娜手机壁纸。关键词是「神性」。出图前后都核对角色还原。

想先看方案，把「给我生成」改成「先给我设计方案」。想做电脑壁纸，直接把「手机壁纸」改成「16:9 电脑壁纸」。

## 设计顺序

用实机和官图校准角色，先定神态、姿势和视线，再设计背景和光线。成图后放大检查眼睛、手势、原服细节和裁切。
