# 角色美图与壁纸创作

这套流程适用于不同游戏、角色和时装。每次沿文档提供的渠道现场搜集、实际看图、拆解并筛选参考，再设计、生成和审图。

- [通用角色壁纸工作流](workflow.md) · 搜图渠道、参考分工、人物设计、壁纸排版与审图。
- [芙宁娜案例](furina-wallpaper-workflow.md) · 荒性形态的辨识特征和检查要点。

## 在新对话里使用

> 请先读 https://github.com/wyy-0704/furina-wallpaper/blob/main/workflow.md ，按流程现场搜集、比较并筛选参考。给「[角色名]」做一张「[手机或电脑]」壁纸。时装是「[时装名，可省略]」，主题是「[主题，可省略]」。出图后复查角色和构图。

想先讨论画面时，把「做一张」改成「先给我设计方案」。
