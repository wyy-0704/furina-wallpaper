# 角色美图与壁纸创作

面向不同作品、角色和时装的手机与电脑壁纸创作流程。每次现场搜图、实际比较，再把学到的构图方法用到人物和背景设计上。

- [通用角色壁纸工作流](workflow.md) · 搜图渠道、参考拆解、人物与背景设计、生成和审图。
- [芙宁娜案例](furina-wallpaper-workflow.md) · 荒性形态的辨识特征和检查要点。

## 在新对话里使用

> 先读 https://github.com/wyy-0704/furina-wallpaper/blob/main/workflow.md 。给「[角色名]」做一张「[手机或电脑]」壁纸，时装和主题可指定。按流程现场搜集并比较参考，挑出具体设计方法用到构图里，出图后复查角色、人体、服装和画面。

想先讨论画面时，把「做一张」改成「先给我设计方案」。
